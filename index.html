Hướng dẫn cài đặt cho iPhone và máy tính. Bạn cần một key bản quyền dạng TN-XXXXX-XXXXX-XXXXX-XXXXX (người bán gửi sau khi thanh toán).

📱 iPhone💻 Máy tính (PC)

💻 Máy tính (Chrome / Edge)

⬇️ Tải tiện ích PC (.zip)
Luôn là bản mới nhất.

Cài lần đầu

  1. Tải file zip ở trên, giải nén vào một thư mục cố định (ví dụ D:\AutoTN). Không xóa hoặc di chuyển thư mục này sau khi cài.
  2. Chrome: mở chrome://extensions (Edge: edge://extensions). Bật Chế độ nhà phát triển (Developer mode) ở góc trên.
  3. Bấm Tải tiện ích đã giải nén (Load unpacked) và chọn thư mục vừa giải nén.
  4. Mở tiennghich.joyplay.vn/play, đăng nhập nhân vật. Bảng điều khiển hiện ở góc trên bên trái.
  5. Vào tab ⚙️ Cài đặt → ô 🔑 Bản quyền → dán key → Kích hoạt. Thấy ✅ Đã kích hoạt là xong.

Cập nhật

  • Tính năng mới tự cập nhật qua máy chủ, bạn không phải tải lại gì. Chỉ cần tải lại trang game.
  • Chỉ khi bản mới ghi Cài lại = Có (bảng bên dưới) mới cần tải zip mới: giải nén đè vào đúng thư mục cũ, mở chrome://extensions và bấm biểu tượng 🔄 trên tiện ích, rồi tải lại trang game.

📱 iPhone (Safari)

Bạn cần: iPhone, app Userscripts (App Store, miễn phí), tài khoản game, và key.

Cài lần đầu

  1. Cài app Userscripts. Vào Cài đặt → Safari → Tiện ích mở rộng → Userscripts: bật, và chọn Cho phép cho cả hai trang tiennghich.joyplay.vn và tiennghich.acejoygame.com.
  2. Mở app Userscripts → Set Directory → chọn một thư mục (ví dụ trong iCloud Drive hoặc "Trên iPhone").
  3. Tạo phím tắt (Shortcuts) tên Cập nhật Auto TN với các bước:
    1. Ask for Input (Text), câu hỏi: Nhập key.
    2. Get Contents of URL: URL https://auto-tn-server.onrender.com/v1/script, Method GET, thêm Header Authorization = Bearer + Provided Input (có dấu cách sau chữ Bearer).
    3. Save File: đích là thư mục Userscripts ở bước 2, bật Overwrite If File Exists, tắt Ask Where to Save, đường dẫn con /tien-nghich-auto.user.js (nhớ đuôi .js).
  4. Chạy phím tắt, nhập key. Lần đầu máy chủ miễn phí có thể mất khoảng 1 phút để thức dậy, cứ chờ.
  5. Đóng hẳn Safari, mở lại, vào tiennghich.joyplay.vn/play và đăng nhập nhân vật. Nút ⚡ xuất hiện.
  6. Chạm ⚡ → tab ⚙️ Cài đặt → ô Bản quyền → dán key → Kích hoạt.

Cập nhật

Tính năng mới tự cập nhật qua máy chủ. Khi có bản vỏ mới: chạy lại phím tắt, đóng hẳn Safari, mở lại.

Giữ iPhone mở khóa và Safari ở phía trước khi chạy Auto (Safari tạm dừng khi khóa màn hình).

ℹ️ Lưu ý chung

  • Key gắn với nhân vật game đầu tiên kích hoạt và dùng tối đa 2 thiết bị (mỗi lúc chỉ 1 thiết bị chạy; thiết bị mới kích hoạt sẽ làm thiết bị cũ dừng). Key dùng được cho iPhone, PC hoặc cả hai tùy gói bạn mua.
  • Xóa dữ liệu trình duyệt được tính là thiết bị mới. Cần đổi nhân vật hoặc reset key thì liên hệ người bán.
  • Cần có mạng để khởi động Auto (máy chủ miễn phí có thể mất tới 1 phút để thức dậy lúc đầu).
  • Dùng công cụ tự động có thể vi phạm điều khoản game và có rủi ro bị khóa tài khoản; bạn tự chịu trách nhiệm.
