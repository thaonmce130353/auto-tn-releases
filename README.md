# Auto Tiên Nghịch — bản tải về

Trang hướng dẫn (iPhone + PC) và liên kết tải: **https://auto-tn-releases.nguyenminhthaobt1.workers.dev/**

Hosting: Cloudflare Workers (`wrangler.jsonc`, thư mục gốc là website, tự build lại mỗi lần push lên `main`). GitHub Pages cũ (`thaonmce130353.github.io/auto-tn-releases`) chỉ còn dùng tạm trong lúc chuyển; tắt nó sau khi khách đã dùng liên kết mới.

Tiện ích PC cần **key bản quyền** để dùng; không có key thì không làm gì. Tải trực tiếp bản mới nhất: [`tn-extension-latest.zip`](tn-extension-latest.zip). Danh sách phiên bản: [`VERSIONS.md`](VERSIONS.md).
